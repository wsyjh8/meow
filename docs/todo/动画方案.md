基于探索结果，我来给你分析适合这个项目的动画方案：

---

## 当前状态

项目几乎**零动画**——只有一个 `AnimatedSwitcher`，没有任何动画包。Flutter SDK 3.0+，Material 3 已启用。

---

## 这个项目的动画分三层

根据 UI Spec 的动效原则（"轻微呼吸感、点按微反馈、奖励轻跳动、互动短动作、装备局部高亮"），我建议分三层实现：

### 第一层：Flutter 内置隐式动画（零依赖，覆盖 80%）

这些是 Flutter 自带的，不需要装任何包：

| 场景 | 用什么 | 效果 |
|---|---|---|
| 状态切换（loading→内容） | `AnimatedSwitcher` | 淡入淡出（已有） |
| 数字变化（coins/exp/mood） | `AnimatedDefaultTextStyle` + `TweenAnimationBuilder` | 数字滚动/跳动 |
| 卡片出现 | `AnimatedOpacity` + `AnimatedSlide` | 轻柔渐入 |
| 按钮按下反馈 | `AnimatedScale` / `AnimatedContainer` | 缩放微弹 |
| 进度条变化 | `AnimatedContainer` / `TweenAnimationBuilder` | 平滑增长 |
| 装备状态切换 | `AnimatedSwitcher` + `AnimatedContainer` | 标签切换高亮 |
| 页面间过渡 | 自定义 `PageRouteBuilder` | 更柔和的页面转场 |

**适合场景**：Today 页、资源栏数字变化、进度条、状态标签切换、按钮反馈

### 第二层：Flutter 显式动画（零依赖，用于关键反馈）

需要 `AnimationController`，但仍不装外部包：

| 场景 | 用什么 | 效果 |
|---|---|---|
| 猫猫呼吸感 | `AnimationController` + `ScaleTransition` 循环 | 微微起伏 |
| 升级庆祝 | `AnimationController` + `SlideTransition` + `FadeTransition` | 弹出+淡入 |
| 喂猫成功反馈 | `AnimationController` + custom `Tween` | 图标轻弹+文字飘出 |
| 状态泡泡出现 | `AnimationController` + `CurvedAnimation(Curves.elasticOut)` | 弹性冒出 |

**适合场景**：猫猫主体区呼吸、升级弹层动效、喂猫/互动反馈

### 第三层：Lottie（可选，用于猫猫角色动画）

如果后续想让猫猫有**真正的动作表现**（不只是静态图标缩放），Lottie 是最合适的：

| 优势 | 劣势 |
|---|---|
| 设计师可独立制作动画 | 需要 Lottie JSON 资产文件 |
| 质量高、流畅 | 增加包体积 |
| 支持状态切换动画 | 需要美术产出 |

**但 B1 阶段不建议引入。** 原因：没有美术资产，Lottie 没素材等于白装。等 B2 或更后期有美术资源时再加。
