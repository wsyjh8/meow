## 2. PR-B3 — mobile manifest 分支（feature flag 默认关）≈ 2 天

**目标**：WordbookLoader 加 if/else 分支，feature flag 控制走 manifest 还是 bundled。flag 默认关，App 默认行为依然不变。

### 2.1 范围（严格对齐原 §B.518-529）

- `WordbookLoader.loadIfNeeded()` 加分支：
  - flag=true → `ContentPackageService.syncIfNeeded()`
  - flag=false（默认）→ 现有 bundled 路径
- flag 通过 `local_settings` 表控制（debug 用）；可加设置页入口或 dev 命令切换
- 关 flag 测既有 bundled 流程不受影响（**回归测试关键**）
- 开 flag 测 manifest 流程通畅（手动验证 + 集成测）

### 2.2 不做

- **不**给最终用户 visible 入口（仍是 debug-only flag）
- **不**改 minimum-set
- **不**减包

### 2.3 完成条件

1. 开 flag 跑一次 → manifest 路径全过
2. 关 flag 跑一次 → bundled 路径不受影响（regression）
3. 用户路径不交付（任何用户首启都看不到"manifest 字样"）

## 3. PR-B4 — 默认开 + minimum-set 600KB ≈ 2 天

**目标**：feature flag 默认开 + bundled 5.6MB 改 minimum-set 600KB。**首次用户可见的减包效果**。

### 3.1 范围（严格对齐原 §B.531-545）

- 生成 `apps/mobile/assets/words/minimum-set.json`（CET-4 前 200 词 + 各 1 例句，目标 ~600KB）
- 删 `apps/mobile/assets/words/{book-001,zk,gk}.json` 三个大文件（5.6MB）
- WordbookLoader：
  - 默认走 manifest（flag 默认 true）
  - 从未 imported 时用 minimum-set 兜底（离线首启）
  - 删 `loadIfNeeded` 旧 bundled 路径
- 重写启动序列：minimum-set bootstrap → 后台 manifest sync 补全

### 3.2 完成条件

1. APK 减小 ~5MB（before/after 对比）
2. 新装设备首启 → 看到 minimum-set 200 词 → 后台拉 manifest → 几秒内补全（手机/Emulator 真机测）
3. **全离线设备首启**仍能学 minimum-set 200 词（critical 验证）
4. 既有用户的本地 SQLite 数据保留（migration 不清理 example_sentences）

### 3.3 风险

- 用户首启网络差 → 看到 minimum-set 200 词，可能困惑
- 离线设备永远拿不到全量（需 UI 提示）
- 既有用户升级时 example_sentences 表已经有数据 → 不重导（migration safety）

## 附录 A：术语对照表（保留 v0.1）

| 术语 | 定义 |
|---|---|
| release | content_release 行，治理 SSOT |
| package | content_manifest 行，物理包文件元数据 |
| package_set | release.package_set 数组（denormalized snapshot） |
| dual-condition | release.status='active' AND manifest.is_active=true |
| revoke | 硬撤回（不可逆，**不可被 rollback 恢复**） |
| deprecate | 软下线（**唯一可被 rollback 恢复的状态**） |
| rollback | `deprecated → active`，同时把当前 active → deprecated（PR-B1） |
| orphan | FS 有文件 / PG 无对应行（PR-B1 orphan-scan） |
| stale | PG 有行 + status='eligible_for_gc'（PR-A gc-stale） |
| **content_package_state** | **drift 表**（PR-B2 新加），追踪 mobile 端已 imported 的 package release_id / version |
| **minimum-set** | **600KB bundled JSON**（PR-B4），仅 CET-4 前 200 词 + 每词 1 例句，离线首启兜底 |
| **feature flag** | **PR-B3 加**，控制 WordbookLoader 走 bundled 还是 manifest，默认关 |
